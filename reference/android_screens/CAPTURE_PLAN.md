# 실기기 화면 캡처 계획

대상: `com.ekkorr.endlessfrontier` 5.5.5, 1080×2400 실기기 화면. 캡처 원본 PNG는 같은 디렉터리에 저장한다. 앱 외 화면이나 개인 정보가 보이면 수집을 중단한다.

## 첫 순회

- `quest_main.png`: 퀘스트 기본 화면
- `soldier_main.png`: 병사 기본 화면
- `relic_main.png` 또는 `relic_locked.png`: 유물 기본/잠금 팝업
- `pvp_main.png` 또는 `pvp_attempt.png`: 대전 목록/잠금 팝업
- `inventory_main.png`: 인벤토리 기본 화면
- `shop_main.png`: 상점 기본 화면

## 하위 화면

- 퀘스트: 스킬/보상, 퀘스트 행 상세, 상단 전투 메뉴
- 병사: 병사 상세·구입·시간의 상점·일괄 강화·장비
- 유물: 구매·시간의 상점·초월·던전
- 대전: 무한랭킹전·일일랭킹전·도전의 탑·차원의 전투·월드 보스·명예 상점
- 인벤토리: 병사·유물·펫·전함 분류와 아이템 상세
- 상점: 보석·버프·프리미엄·병사 상점 및 상품 상세
- 그 외: 펫·길드·전함·업적·설정·각종 팝업은 접근 경로를 확인해 별도 캡처

스크린샷마다 `CAPTURE_LOG.md`에 진입 순서, 잠금 조건, 팝업 여부, 기기/앱 상태를 적는다. 첫 환생이나 구매 등 복구하기 어려운 행동은 화면 수집 목적으로 임의 실행하지 않는다.
